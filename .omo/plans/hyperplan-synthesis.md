## Critical Gaps the Plan Missed (Lateral-Critic's Uncontested Findings)

These are the highest-severity findings from the entire hyperplan. They represent issues that could cause desk rejection at top-tier venues and were completely absent from the original plan. Lateral-critic was the ONLY critic to identify them.

### Gap A: Human-Text Overlap (6029 duplicates) — MUST FIX
- 6,029 of 5,000 held-out human samples have been seen in training (~60% contamination)
- Held-out metrics are inflated by an unknown amount (directional: boosts human accuracy → boosts AI precision → boosts held-out F1)
- Fix: add a `pandas.drop_duplicates()` step in preprocessing with seed-aware train/held-out splitting. Rerun inference on clean split. Report metrics on both contaminated AND deduplicated splits.
- Effort: ~2-3 hours (no GPU)

### Gap B: Multi-Seed Evaluation — MUST FIX
- Entire ablation ranking rests on differences of 0.4-1.6 pp with no error bars
- RRD values span only 2 points (1.11% → 3.13%) — indistinguishable without error bars
- The paper admits this in Limitations but budgets zero compute to fix it
- Fix: Run all 4 configs × 3 seeds (or 5) = 12-20 runs. Report mean ± std for all metrics.
- Effort: ~12-15 hours GPU time (RTX 3050 @ ~1.1 hr/config)

### Gap C: Missing Simple Baseline (TF-IDF + LR) — SHOULD FIX
- No non-neural baseline to justify "deep learning for robustness" framing
- If a TF-IDF model achieves 0.90 held-out F1, the contribution narrative changes
- Fix: Train TF-IDF + Logistic Regression on same split. Report all metrics.
- Effort: ~2 hours (data prep + training, minimal GPU)

### Gap D: Unfair FDG Comparison Framing — SHOULD FIX
- DistilBERT: held-out F1 on non-adversarial generator holdout (0.913–0.927)
- Fast-DetectGPT: adversarial AUROC on attack subsets (0.526–0.789)
- Different metrics, different splits, different conditions — repeatedly framed as evidence of superiority
- Fix: Either (a) run FDG on same generator holdout split, (b) run DistilBERT on same attack subsets, or (c) remove direct comparison framing entirely. (a) is most practical if FDG is renamed to "perplexity baseline" (its actual implementation).
- Effort: ~3-4 hours if already renamed (running perplexity baseline on new split)

### Gap E: Clean-Only Training Baseline — SHOULD FIX
- Paper admits it can't distinguish whether adversarial augmentation helps or hurts
- Train ablation_b on clean-only RAID data. Compare RRD with vs without adversarial data.
- Effort: ~1 hour (one run)

### Gap F: Systems Benchmarks Compress — NICE TO FIX
- Reduce ~4 figures + ~3 tables on standard PyTorch optimizations to 1 paragraph + supplementary
- Moves detection science narrative to the foreground
- Effort: ~1 hour (text editing)
